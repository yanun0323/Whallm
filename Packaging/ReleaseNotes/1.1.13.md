# Whallm 1.1.13

Changes since v1.1.12.

## Native engine for both Qwen models

- Qwen3.8-Flash-Next and Swift1.5-Qwen3.8-Flash-Next now run on the bundled C++ and Metal engine instead of MLX.
- Existing model downloads, display names, API model IDs and Aliases stay unchanged. Both models support text, still images, MTP and Prompt Cache.
- **Size the expert cache automatically** uses the memory available when a model loads, up to 8,192 slots. Turn it off to choose a fixed cache size.
- New or reset settings enable automatic expert cache sizing, MTP and **Use 8-bit resident weights**. Saved generation, read-worker, MTP and 8-bit choices are retained.
- Advanced Settings no longer shows MLX-only controls or a separate MTP expert cache size for these models.

## Model settings and API

- **Context window** sets the maximum combined input and output length for each request, within the model's supported limit. Requests that exceed it return `context_length_exceeded`.
- `GET /v1/models` includes each model's context window and capabilities in its `data` entries.
- The model list shows newer models first and no longer clips the available rows into a short inner list.
- Throughput durations use units appropriate to their length.

## Upgrade notes

- Quit the old App before opening this version. Model weights do not need to be downloaded again.
- MLX Prompt Cache files are not reused by the Native engine; prompts are processed again as needed. Native output can differ from MLX output.
- The two temporary `-native` preview model IDs have been removed. If you used them, switch to `qwen3.8-flash-next-fp8` or `swift1.5-qwen3.8-flash-next-mxfp4`.
- Custom Qwen runtime configurations must leave MLX-only options at their defaults; other values are rejected. The App handles this automatically.
- Clients reading the former top-level `models` or `object` fields from `GET /v1/models` must use the `data` array instead.

## Validation and limits

- 767 Python tests ran with one skipped and no failures; 199 Swift tests ran with four skipped and no failures. All 24 release-script tests passed.
- Local App and ZIP checks passed for signatures, bundled model files, and startup in English, Simplified Chinese and Traditional Chinese without access to the build folder or Swift localization bundle.
- Prior Native checks on M2 Max covered short text, Chat, Responses, streaming and images for both models. Broad quality, performance and M5 validation remain incomplete. Earlier MLX benchmarks do not describe this engine.

Requires Apple Silicon and macOS 15 or later. Model weights are downloaded separately. Distribution builds exclude local-only debug and Dry run features.
