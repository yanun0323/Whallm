# Whallm 1.1.11

Changes since v1.1.10.

## Qwen images with MTP

- Send images to both Qwen models with MTP on. The main model and the MTP draft layer now receive the image content and its positions, following the pairing used by vLLM's MTP drafter.
- You no longer need to turn off MTP and reload the model before sending images. Image requests still skip the prompt cache.
- On the full Swift1.5 model, red, blue and two-image prompts were answered correctly with MTP on, and every token MTP produced matched the model's own greedy choice. Output was about 1.4× faster than with MTP off on two test images.

## Faster Qwen MTP

- MTP is now on by default for both Qwen models, with 2 draft tokens. It turns off for a request only after 32 rounds in a row with no accepted draft.
- When the main model checks drafts, it starts computing each expert as soon as that expert is in memory instead of waiting for all of them. Output is unchanged. On the M5 Pro with Swift1.5, output was 8–18% faster and the first token was not slower.
- The prompt cache now works with MTP. Saved entries include the draft layer's state and are kept apart from non-MTP entries.
- The App starts the runtime with smaller MLX command buffers when every installed model uses the Qwen engine. Output was 2–4% faster on Swift1.5 with identical tokens and no extra memory.
- Sorted expert Prefill and masked QSA Prefill are now always on for Qwen.

## Simpler Qwen settings

- Both Qwen models show the same short **Advanced Settings** list: Alias, generation, experts in memory, read workers, MLX memory guideline, Prompt Cache, warmup and MTP. Every other Qwen option uses a fixed value.
- Set the number of experts kept in memory as a percentage, with the estimated memory use and slot count shown next to it.
- The memory estimate shows the cost of one request as the main number and the full Prompt Cache limit on a second line. **Throughput** shows the same estimate under the measured peak memory, and its table now scrolls sideways.
- The **Advance** page in the sidebar is renamed **Performance**.

## Removed Qwen experiments

- Removed sparse SDPA, indexed QSA and shared-expert overlap. Model catalogs that still list these options as `false` keep working; `true` is rejected with an error.
- Approximate mode is no longer offered for Qwen. API requests that ask for it on a Qwen model return `400`. DeepSeek keeps approximate mode.

## Chat

- Your messages now appear as bubbles on the right. Replies use the full width and show bold, italic, code and links.
- Reasoning folds away once the answer starts; you can open it again.
- The message box is smaller, Seed moved to the bottom row, and the "Enter a message…" hint is now visible.
- Long waits, such as processing a long prompt, no longer let Chat and tool-call streams go quiet: the server sends an empty update every 10 seconds.

## Upgrade notes

- Qwen settings that are now hidden are replaced by fixed values. Your Alias, generation, memory, worker, Prompt Cache, warmup and MTP settings are kept.
- MTP turns on by default for Qwen. MTP output can differ slightly from output with MTP off. Turn off **Use MTP** in **Model → Advanced Settings** if you need the non-MTP output.

## Validation

- **705 Python tests passed**; **193 Swift tests ran, with 4 skipped and no failures**.
- Packaging checks cover signatures, bundled files and startup in English, Simplified Chinese and Traditional Chinese without access to the build folder, for both the App and the unzipped download.

## Known limits

- Speed and image results come from one M5 Pro with Swift1.5 only. Qwen3.8 FP8 was not measured for the new defaults, image input with MTP, or faster verification.
- Image checks use simple generated images and short answers. They do not measure image quality in general.
- MTP is not faster for every prompt.

Requires Apple Silicon and macOS 15 or later. Model weights are downloaded separately. This is a distribution build; local-only debug and Dry run features are not included.
