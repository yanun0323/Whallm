# Whallm 1.1.14-dev.1

Development prerelease. Changes since v1.1.13. Select **Settings → Updates → Dev** to receive dev updates; the stable channel remains on v1.1.13.

## DeepSeek V4.1 Native engine

- DeepSeek V4.1 now uses the bundled C++ and Metal Native engine instead of MLX, including text generation, DSpark and Memory/Disk Prompt Cache.
- Existing model files, API model ID, installation and Alias stay unchanged. DSpark experts share the main expert cache.
- Automatic expert cache sizing uses available memory at model load, from 256 to 4,096 slots. Fixed caches must hold at least 96 experts.
- Advanced Settings no longer offers MLX-only controls for this model. Approximate mode and incompatible MLX-specific runtime options are rejected.
- Developer messages are encoded as system messages for DeepSeek V4.1, including tool conversations.

## App and logging

- Fix the main window layout so navigation and Logs remain visible, including at smaller window sizes.
- Add runtime event logging and an optional **Save logs to file** setting. File logging is off by default and keeps at most 10 MB in `~/.whallm/server.log`, removing oldest lines first.
- Debug events omit full prompts, tool results, images and API keys. Logs can still contain local paths and network addresses; review them before sharing.

## API output limits

- Tool-enabled requests that exhaust their output budget preserve the length-limit result rather than failing solely because thinking or tool markup is unfinished.
- Chat keeps `finish_reason: "length"` and token usage. Responses reports `status: "incomplete"`, `incomplete_details.reason: "max_output_tokens"`, and `response.incomplete` for streaming requests.
- Required-tool requests do not spend a second output budget after reaching the limit. Malformed completed output remains an error.

## Upgrade and validation limits

- Quit the old App and restart with this build. No model redownload is required. DeepSeek V4.1 prompt caches from MLX are not reused; native caches rebuild on demand. Saved MLX-only tuning no longer applies.
- This is a dev build, not a new stable release. MiMo remains a preview, and the server still handles one generation request at a time.
- API regression tests use fixed model output; they do not establish real-model tool quality or full Pi/Codex compatibility.
- Earlier DeepSeek V4.1 checks on M2 Max observed greedy output matching MLX. These are limited observations, not broad quality validation. Inputs longer than 16,000 tokens and M5 performance remain unvalidated; DSpark speed has not been remeasured after the latest changes.
- No new real-model performance or quality measurements are claimed for this release. See [the usage reference](https://github.com/yanun0323/Whallm/blob/v1.1.14-dev.1/docs/usage.md) and [benchmark limitations](https://github.com/yanun0323/Whallm/blob/v1.1.14-dev.1/BENCHMARK.md).
