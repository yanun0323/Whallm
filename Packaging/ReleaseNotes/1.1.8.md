# Whallm 1.1.8

Changes since v1.1.7.

## Chat and sampling

- Keep long Chat responses inside a scrollable viewport instead of letting the transcript expand the app window. The message composer stays outside the response scroll area.
- Add a per-message Seed field to Chat and optional unsigned 32-bit `seed` support to all three generation endpoints. Omitting the seed now uses a fresh random seed for each request rather than reusing a fixed request seed.

## Runtime and model settings

- Improve DeepSeek V4.1 layer-major prefill with contiguous expert layer buffers, request-scoped buffer reuse, and batched expert processing. Enable V4.1 layer-major prefill and next-layer prefetch by default in the runtime and CLI.
- Support V4.1 DSpark with layer-major prefill and next-layer prefetch, while retaining the restrictions on CED, DSpark prompt caching, and sequential verification.
- Add separate Prefill/Decode I/O policies and an optional route-aware expert cache eviction policy alongside LRU and LFU.
- Enable supported layer-major processing, ready-expert computation, expert batching, and next-layer prefetch in new or reset App settings. Explicitly saved disabled settings are preserved.
- Add Qwen pooled index caching, optimized N-gram lookup, compiled tensor operations, and phase-aware expert cache sizing, enabled in new or reset Qwen App settings. Add optional MTP draft-depth and zero-acceptance retry controls; MTP and its custom strategy remain off by default.
- Add memory budgets and peak estimates to model settings, GiB cache sliders, a persistent slots-editing preference, and a two-step reset for the selected model's advanced settings. Slots editing is enabled by default.
- Update new/reset App defaults, including LRU expert eviction, in-memory prompt caching, an 8,192-token output limit, and GPU-only ANE allocation. Saved settings are retained.

## Throughput and memory reporting

- Add a 512-token output option alongside 128, 1,024, and 4,096 tokens, with matching server validation.
- Fix Throughput sampling to `temperature=0` and `seed=42` for every trial and include sampling settings in exported results. Chat sampling is unaffected.
- Report Whallm plus its Python inference process's physical memory footprint in Throughput and Status instead of MLX allocation or RSS. Retain sampled Status peaks between UI updates and reset them with Clear metric history.
- Use nominal 10 ms memory sampling during model work and 1-second sampling while idle. Unavailable memory readings remain unavailable rather than falling back to a different metric.

## Packaging and documentation

- Validate framework-based Python environments and restore required Python framework symlinks when packaging.
- Update multilingual documentation, preserve historical benchmark context, and keep local research archives out of the public checkout.
- Expand regression coverage to 135 Swift tests and 464 Python tests.

## Notes

Acceleration changes have component and regression coverage, but this release does not claim a new full-model speedup or a completed DeepSeek V4.1 quality validation. Historical PR measurements are not measurements of this release. The previously observed Qwen MTP/non-MTP output difference remains unresolved. Fixed seeds do not guarantee identical output across versions, cache states, or acceleration settings.

Requires Apple Silicon and macOS 15 or later. Model weights are downloaded separately. This is a distribution build; local-only debug and Dry run features are not included.
